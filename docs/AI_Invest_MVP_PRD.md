## 1. 产品摘要

AI Invest 是一款个人使用的 macOS AI 投资工作台。它将长桥账户中的持仓与行情、个人投资策略、结构化研究数据、AI 建议和学习成长连接起来，帮助用户持续回答五个问题：

1. 我现在持有什么，组合发生了什么变化？
2. 每项持仓为什么存在，是否仍符合原定策略？
3. 最新行业与公司研究改变了哪些关键事实或假设？
4. 今天最需要关注、研究或调整的事项是什么？
5. 我今天应该学习什么，怎样逐步形成自己的资产配置、选股和行业研究方法？

产品不以预测短期涨跌为核心，也不直接执行交易。MVP 的核心闭环是：

```text
定时或手动同步账户与研究数据
      ↓
形成可验证的组合快照
      ↓
检查风险和策略偏离
      ↓
关联持仓新闻、历史研报与本地策略证据
      ↓
生成可解释的行动建议
      ↓
记录用户决策与后续结果
      ↓
进入下一次复盘
```

## 2. 背景与问题

### 2.1 用户现状

个人投资通常分散在券商账户、行情页面、基本面数据、机构观点、公告、新闻、笔记和临时判断中。长桥已经提供账户、组合分析、行情和丰富的结构化研究数据，但这些信息尚未形成统一的投资决策系统。

### 2.2 核心问题

- 持仓页面能展示资产，却不能解释组合风险和收益来源。
- 投资逻辑经常停留在记忆中，买入后缺少持续验证。
- 财务数据、评级、一致预期、公告和新闻分散，难以判断哪些变化真正影响现有持仓。
- 通用 AI 容易给出缺少来源、忽略个人策略的泛化建议。
- 用户的接受、忽略和实际决策没有被系统记录，无法复盘。

### 2.3 产品机会

建立一个以个人组合为中心的“投资操作系统”：所有研究和建议都必须关联到具体持仓、策略、规则与证据，并保留完整决策记录。

## 3. 产品定位

### 3.1 一句话定位

面向稳健型港股投资者的个人 AI 投资工作台，让每一项持仓都有策略、每一条建议都有证据、每一次决策都能复盘。

### 3.2 核心价值

- **看清组合**：统一展示资产、收益、仓位和风险暴露。
- **遵守纪律**：把投资策略变成可检查的规则，而不是模糊偏好。
- **提高研究效率**：从财务报表、经营数据、估值、机构评级、公告和新闻中提取与持仓最相关的事实、观点和风险。
- **形成行动清单**：把信息转化为有优先级、可解释、可处理的建议。
- **积累个人认知**：记录投资论点、决策理由和复盘结果。

### 3.3 产品原则

1. 证据优先于结论。
2. 风险控制优先于收益预测。
3. 规则先触发，AI 再解释。
4. 不因单日行情制造过度交易压力。
5. 关键数字由程序计算，不由模型自由推算。
6. 用户拥有最终决策权，MVP 永不自动下单。
7. 默认本地优先存储，最小化向 AI 服务发送的数据。

## 4. 目标与非目标

### 4.1 MVP 目标

- 用户可在 5 分钟内连接长桥并看到可信的港股持仓快照。
- 用户可手动录入长桥之外的基金、加密货币、债券、现金和其他资产，并统一折算到组合基础币种。
- 用户可为组合和持仓建立结构化的稳健投资策略与投资论点。
- 系统可将长桥的持仓相关新闻与行业、公司、持仓和策略建立关联；完整基本面、估值、评级和公告证据层列为后续增强。
- 用户可为持仓行业设置 GPT 定时研究任务，周期生成带来源、可对比的 AI 行业研报。
- 每条 AI 建议都包含触发原因、数据时间、证据来源、风险与置信度。
- 用户可接受、忽略、延后或完成建议，并记录最终决策理由。
- 系统支持每日快速查看和每周组合复盘。
- 断网时仍能查看最近一次同步的数据和已保存的研究记录。
- 用户可在 4 周内完成 28 天最小必要课程，形成资产配置规则、选股评分卡、行业分析模板和《个人投资手册 v1.0》。
- Codex 可每天生成一节课程，并通过项目 `Learning/` 文件夹与应用中的进度、方法论和提问上下文衔接。

### 4.2 MVP 非目标

- 不提供交易下单、自动交易、条件单或券商写入操作。
- 不承诺预测价格、收益率或提供确定性目标价。
- 不做高频行情终端或分钟级交易信号。
- 不做完整量化回测、因子研究和策略市场。
- 不提供非港股资产的自动行情、基本面与完整研究；基金、加密货币、债券等在 MVP 中仅支持手动持仓与估值管理。
- 不提供社交、跟单、排行榜和公开内容社区。
- 不面向其他用户提供受托资产管理或个性化投顾服务。

## 5. 用户画像与使用假设

### 5.1 核心用户

- 单一用户，个人自用。
- 主要投资港股股票和 ETF。
- 偏稳健、中低频交易，关注基本面、行业趋势和风险控制。
- 典型持仓数量按 5–50 个标的设计。
- 可能有 1–3 个长桥账户，但 MVP 首先保证一个主账户完整可用。
- 主要在收盘后、开盘前和周末进行研究与复盘。

### 5.2 核心任务

- 早上快速确认组合是否出现必须关注的变化。
- 收盘后理解当日盈亏来源和异常波动。
- 阅读与持仓有关的新研究事件，识别财务、评级、预期、公告或新闻变化。
- 按周查看 GPT 自动生成的持仓行业研报，减少重复搜集和整理工作。
- 检查仓位、行业集中度和投资逻辑是否偏离策略。
- 每周形成一份组合复盘与下周行动清单。

## 7. 信息架构

macOS 应用采用左侧固定导航，只保留五个一级菜单 Tab：

| 一级 Tab | 定位 | 二级页面或核心内容 |
| --- | --- | --- |
| **持仓** | 默认首页，回答“我现在持有什么、发生了什么” | 组合总览、持仓列表、持仓详情、风险摘要、公司研究证据 |
| **策略** | 管理投资纪律与持仓逻辑 | 组合策略、持仓论点、规则检查、策略版本 |
| **建议** | 管理需要关注和处理的事项 | 待处理、全部建议、决策日志、周复盘 |
| **行业研报** | 查看行业变化并管理 GPT 定时研究 | 最新研报、行业分类、机构观点、定时任务、运行历史 |
| **学习** | 从零建立个人投资方法论 | 今日学习、学习路径、复习、我的方法论、学习笔记 |

原“今日”能力合并到“持仓”首页，不再单独占用一级 Tab。原“决策日志”和“周复盘”作为“建议”的二级页面；设置通过左侧栏底部齿轮进入，不属于一级 Tab。

推荐窗口结构：

- 左栏：一级导航。
- 中栏：列表、筛选或摘要。
- 右侧主区域：详情、图表和操作。
- 右侧检查器（按需）：来源、规则、关联对象和元数据。
- “建议”和“行业研报”可在左侧 Tab 显示未读数量徽标；风险数量不使用闪烁动画。

## 8. 详细功能需求

### 8.1 首次启动与数据连接

#### 8.1.1 首次启动流程（P0）

1. 首次启动直接进入明确标注的模拟模式，可完整浏览而不要求外部凭证。
2. 用户在设置中安装或检测长桥官方终端，通过浏览器完成 OAuth 授权并测试连接。
3. 连接成功后切换到真实模式，同步主账户组合、持仓、价格和现金。
4. 用户可选择配置自有 OpenAI API Key；未配置时行业研报使用本地模拟。
5. 基础币种默认为 HKD；策略默认为“稳健港股”。
6. 对未识别行业的长桥持仓添加本地行业标签。
7. 首次运行行业研报任务，检查新闻来源与 GPT 输出边界。

#### 8.1.2 连接要求（P0）

- 明确显示连接成功、OAuth 授权失败、权限不足、行情权限等级、限流、令牌失效和网络异常。
- 只申请完成读取所需的最小权限。
- OAuth 访问令牌和刷新令牌由长桥官方终端的加密凭证缓存管理；AI Invest 不读取或复制令牌。
- 应用不提供 App Key、App Secret、Access Token 或交易凭证输入框。
- 连接后检测官方组件、令牌状态、服务连通性和组合读取能力。
- 用户可以断开连接并删除本地缓存。
- 所有页面显示最近成功同步时间。

#### 8.1.3 验收标准

- 正确授权可完成测试和首次同步。
- 授权失败或权限不足不会被保存为完整可用连接。
- 应用重启后无需重新输入凭证。
- 断开账户后停止同步，但保留历史数据，直到用户选择删除。
- 应用中不存在任何交易入口或券商写入调用。

### 8.2 持仓首页

“持仓”是默认一级 Tab，其首页承接原“今日”能力，目标是在 3 分钟内让用户理解当前组合状态并确定下一步。

#### 8.2.1 页面内容（P0）

- **资产摘要**：总资产、持仓市值、现金、当日盈亏、累计持仓盈亏。
- **组合变化**：当日收益贡献最大的三个标的和拖累最大的三个标的。
- **风险状态**：集中度、行业暴露、异常波动、数据异常。
- **策略状态**：当前违反或接近违反的策略规则。
- **行动建议**：按优先级展示最多五条未处理建议。
- **新研究事件**：过去 24 小时内与持仓相关的评级变化、预期变化、公告、公司行动、新闻和已完成的定时行业研报。
- **数据时间**：行情、持仓、组合分析和各类研究数据的最后更新时间。

#### 8.2.2 交互（P0）

- 点击资产或风险卡进入相关持仓详情。
- 点击建议打开完整证据、规则和影响分析。
- 建议支持“接受”“忽略”“稍后提醒”“转为研究任务”。
- 点击研究事件可查看 AI 解读、结构化数据和原始来源链接。
- 支持手动重新生成持仓摘要，但相同数据不重复创建同类建议。

#### 8.2.3 验收标准

- 数据同步成功后首页在 10 秒内展示可用摘要。
- 未取得完整数据时明确显示缺失项，不生成伪造数字。
- 建议卡能追溯到至少一条规则或一项可验证的研究证据。
- 首页不使用闪烁、倒计时或强刺激设计推动交易。

### 8.3 我的持仓

#### 8.3.1 组合总览（P0）

展示：

- 总资产、证券市值、现金、未实现盈亏。
- 股票、ETF 和现金的资产分布。
- 行业分布和单一标的集中度。
- 当日盈亏贡献与累计持仓盈亏贡献。
- 数据完整度与待核对项。

当长桥能够提供完整历史资金流水时，可计算时间加权收益率；否则只展示券商持仓盈亏和区间市值变化，并明确口径，禁止将两者混称为组合收益率。

#### 8.3.2 持仓列表（P0）

默认列：

- 股票代码与名称
- 行业
- 持仓数量
- 当前价格
- 平均成本
- 持仓市值
- 当日盈亏
- 累计持仓盈亏
- 组合权重
- 关联策略
- 风险状态
- 数据时间
- 资产类型与数据来源（长桥同步 / 手动录入）

支持按权重、盈亏、行业、风险等级排序，支持按股票名称或代码搜索。

#### 8.3.3 手动录入持仓（P0）

- “持仓”页提供明确的“录入持仓”入口。
- 支持股票、基金、ETF、加密货币、债券、现金和其他资产类型。
- 必填字段：资产名称、资产类型、持有数量、当前价格或净值、原始币种、兑组合基础币种汇率。
- 可选字段：代码或标识、行业或分类、平均成本、今日涨跌幅、托管平台和备注。
- 手动持仓使用独立 ID 和“手动录入”来源标识；可与长桥中的同代码资产并存，但重复时提示用户核对。
- 市值、成本和盈亏先按原币种计算，再按保存的汇率折算到组合基础币种；聚合结果必须注明基础币种。
- 手动资产不伪装为实时行情，显示最近编辑时间，并提示用户自行更新价格、净值和汇率。
- 支持编辑和删除；删除前二次确认。
- 手动持仓保存在 Mac 本机。长桥同步只替换长桥来源快照，不覆盖、删除或重复创建手动持仓。

#### 8.3.4 本地交易与现金账本（P0）

- 用户可为现有持仓记录买入或卖出成交，包括数量、价格、费用、币种、汇率、成交时间和备注。
- 交易记录仅写入本机账本，不调用长桥下单、改单、撤单或任何券商写入接口。
- 长桥持仓始终以券商同步快照为准；其本地交易默认只用于复盘，不反向修改券商持仓。
- 手动持仓可选择让交易同步更新数量和平均成本；卖出数量不得超过当前持仓。
- 用户可选择让交易同步更新基础币种现金；默认关闭，避免与券商现金重复计算。
- 现金、持仓当前状态、价格时间序列和交易历史使用 SQLite 事务写入。
- 数据库启用 WAL、外键检查、版本迁移和完整性检查；设置页展示各类记录数量和数据库状态。
- 从旧版轻量存储升级时迁移已有手动持仓，迁移失败时不得覆盖原数据。

#### 8.3.5 持仓详情（P0）

- 当前持仓与盈亏信息。
- 价格走势与成本线。
- 组合权重和行业权重。
- 关联投资策略。
- 当前投资论点及失效条件。
- 相关财务、评级、预期、公告、新闻与最新观点变化。
- 未处理建议和历史决策。
- 数据来源与更新时间。

#### 8.3.6 风险检查（P0）

初始提供以下可配置规则：

- 单一标的权重达到 12%：关注；达到 15%：高优先级提醒。
- 单一行业权重达到 25%：关注；达到 30%：高优先级提醒。
- 现金比例低于 10%：流动性提醒。
- 标的从近 20 个交易日高点回撤达到 10%：触发“重新检查论点”，不直接给出卖出结论。
- 单日价格变化超过 8%：触发财务日历、公告、评级与新闻检查。
- 持仓缺少策略或投资论点：触发完善信息提醒。

以上阈值仅为初始化默认值，用户可修改或关闭。

#### 8.3.7 验收标准

- 持仓数量、市值、成本和现金与长桥数据在同一时间点和同一口径下可核对。
- 所有聚合数值可以追溯到具体持仓。
- 缺少成本、行业或公司行动数据时显示异常标记。
- 行业权重和单股权重之和的计算口径明确。
- 非港股资产显示为“不在 MVP 分析范围”，不被静默遗漏。
- 新增、编辑或删除手动持仓后，组合市值、权重、行业分布和盈亏立即重算。
- 重新启动应用后，手动持仓仍然存在；执行长桥刷新后手动持仓不丢失。
- 加密货币和基金的小数份额不得被整数化；跨币种资产必须展示原币现价与基础币种市值。
- 应用重启后现金、持仓、价格记录和本地交易仍可读取，数据库完整性检查通过。
- 本地交易记录必须明确标注“不执行交易”；记录长桥标的时不得修改券商持仓快照。

### 8.4 策略

#### 8.4.1 策略对象（P0）

每份策略包括：

- 名称、状态和版本。
- 投资目标与时间跨度。
- 适用市场和股票范围。
- 核心投资逻辑。
- 入场条件。
- 加仓与减仓条件。
- 退出和论点失效条件。
- 单股、行业和现金仓位规则。
- 允许与禁止的资产类型。
- 复盘频率。
- 基准指数。
- 关联持仓。

#### 8.4.2 “稳健港股”默认模板（P0）

- 目标：控制永久性损失风险，在中长期内获得相对稳健的资本增值。
- 投资范围：港股上市公司和港股 ETF。
- 默认禁止：杠杆、期权、卖空和自动交易。
- 决策依据：基本面变化、估值区间、行业趋势、公司治理与组合风险。
- 默认复盘：每日只看异常，每周组合复盘，每月策略复盘。
- 默认仓位阈值：采用 8.3.6 中的初始化规则。

#### 8.4.3 持仓投资论点（P0）

每个持仓可记录：

- 为什么持有。
- 关键事实与假设。
- 主要催化剂。
- 主要风险。
- 需要持续跟踪的指标。
- 论点失效条件。
- 目标持有周期。
- 最近复核时间。

#### 8.4.4 策略检查（P0）

- 每次持仓同步后运行确定性规则检查。
- 发现偏离时创建“策略偏离事件”。
- AI 自动过程只能解释偏离的原因、可能影响和可选行动，不得静默修改规则。
- 用户可在策略页明确确认一次 Codex CLI 生成；生成结合当前组合、最近研报、实时公开信息和金融理论，更新策略说明、风险阈值及当前持仓论点。
- Codex 以只读、临时、严格结构化输出方式运行，不得读取项目文件、发起交易或输出具体下单数量、目标价和收益承诺。
- 用户仍可手动编辑生成结果；策略规则的确定性检查不交给模型计算。

#### 8.4.5 验收标准

- 用户可以创建、编辑、复制、归档策略。
- 每个持仓可以关联一个主策略和一份投资论点。
- 规则检查使用保存的策略版本，可复现历史结果。
- 修改规则不会重写历史建议和历史决策。
- 手动 Codex 生成成功后可显示摘要、理论依据、近期背景和可点击的 HTTPS 来源；失败时保留原策略。

### 8.5 行业研报（含公司研究证据）

“行业研报”是第四个一级 Tab。其核心是行业变化、GPT 定时研报和历史运行记录；公司研究卡作为行业研报的证据层，也可从“持仓详情”进入。这样公司研究不会额外占用一级导航。

截至本文更新时间，在长桥公开接口清单中未找到券商研报全文、作者、页码或正文端点。MVP 因此不把“研报全文库”作为已确认能力，而是先用长桥已确认的结构化数据、公告文件链接和新闻摘要建立可验证的行业研报中心。若用户另有可用的研报全文接口，可按同一证据模型接入。

#### 8.5.1 研究数据同步（P0）

针对当前持仓和观察列表同步：

- 公司资料和行业分类。
- 利润表、资产负债表和现金流量表。
- 经营摘要、业务分部和关键指标。
- 当前估值与历史估值区间。
- 机构评级分布、评级历史、机构目标价和评级变化。
- EPS 预测及收入、净利润、EPS 等一致预期。
- 分红、回购、拆股、合并、供股等公司行动。
- 监管公告列表、文件名、发布时间和原始文件 URL。
- 个股新闻标题、摘要、发布时间和详情 URL。
- 财报、派息、拆股、股东大会和宏观事件日历。
- 行业排名、行业层级、行业涨跌和同业信息。

首次同步只抓取持仓所需数据；历史财务、估值和价格数据按需拉取并本地缓存。所有增量数据使用来源 ID、标的和时间去重。

#### 8.5.2 行业研报首页（P0）

行业研报首页分为五类信息：

- **需要注意**：评级或一致预期明显变化、财报发布、重大公司行动、与投资论点冲突的事件。
- **持仓更新**：按持仓显示新公告、新闻、财务和估值变化。
- **行业视图**：持仓所在行业的组合权重、行业排名、估值位置和近期表现。
- **定时研报**：展示最新 AI 行业研报、下次运行时间、任务状态和最近失败原因。
- **机构观点**：展示 Morgan Stanley、Bridgewater、Goldman Sachs 和 J.P. Morgan 的官方公开研究入口、任务覆盖数和已采用原文；明确桥水是资产管理机构。

支持按公司、行业、来源类型和日期筛选；优先展示与持仓和已保存投资论点直接相关的内容。

行业分类规则：

- 每份研报保存一个主行业；跨行业组合研报归入“全部持仓行业”，同时可从“全部行业”查看。
- “最新研报”按生成时间展示，并提供“全部行业”和各行业快捷筛选。
- “行业分类”按主行业建立目录，展示研报数量、未读数量和最近更新时间。
- 点击行业后只展示该行业研报，新生成研报自动进入对应分类，不需要用户手动整理。
- 持仓行业暴露与研报分类分别计算：没有研报不等于没有行业持仓或风险暴露。

#### 8.5.3 公司研究卡（P1）

每个持仓生成一张可刷新、可追溯的公司研究卡：

- 公司与行业概览。
- 收入、利润、现金流和关键财务指标的历史变化。
- 业务分部结构和经营摘要。
- PE、PB、PS、股息率等估值指标及历史区间。
- 机构评级分布、目标价范围和最近评级变化。
- EPS、收入和净利润一致预期；已披露时展示实际值与预期差异。
- 分红、回购、公司行动和重要日历。
- 最新公告和新闻。
- 与用户投资论点相符、冲突和仍待验证的证据。

#### 8.5.4 行业研究（P0）

- 使用长桥行业排名和行业层级构建港股行业树。
- 展示用户在每个行业的仓位、盈亏贡献和集中度。
- 展示行业涨跌、年初至今表现、估值和同业层级。
- 允许从行业进入相关持仓和观察标的。
- AI 可以总结行业变化，但必须列出使用的公司或行业数据和截止时间。
- 每个行业页可创建、暂停或立即运行 GPT 定时行业研报任务。

#### 8.5.5 AI 研究解读（P0）

AI 对一次研究事件或公司研究卡输出：

- 一句话变化摘要。
- 已确认事实和具体指标。
- 机构观点或一致预期。
- 与上一期相比发生的变化。
- 对当前投资论点的支持、冲突或无关判断。
- 主要风险、反面证据和缺失信息。
- 可能的后续研究动作。
- 来源链接、来源类型和数据截止时间。

AI 必须区分“长桥结构化数据”“公告/新闻摘要”“机构观点”“用户输入”和“AI 推断”。目标价只作为机构观点展示，不转化为系统自己的目标价。

#### 8.5.6 研究沉淀（P0）

- 用户可将任一指标、评级变化、公告或新闻摘要保存到持仓论点。
- 保存内容包含来源对象、原始值、时间、链接和保存时的数据快照。
- 用户可以标记为“支持论点”“反对论点”“待验证”。
- 新数据与既有论点冲突时生成研究提醒，不自动修改论点。

#### 8.5.7 GPT 定时行业研报任务（P0）

用户可以为持仓暴露行业或自选行业创建周期性研究任务。任务按保存的范围、频率和研究模板自动同步数据、调用 GPT 生成结构化行业研报，并将结果送入“行业研报”Tab。默认不扫描港股全市场，优先覆盖用户有持仓的行业。

**任务配置**：

- 任务名称和行业范围；支持单个行业或“全部持仓行业”。
- 频率支持交易日收盘后、每周和每月；MVP 默认模板为“每周六 10:00，Asia/Hong_Kong”。
- 模板决定下一次运行周期；界面显示启用/暂停状态、上次与下次运行时间。
- 研究窗口默认为上次成功运行至本次运行；首次运行默认回看最近 7 个自然日。
- MVP 固定聚焦组合暴露、持仓新闻、上一期变化、反面证据和待核验事项。
- 内置“交易日收盘简报”“每周行业研报”和“月度深度跟踪”三种模板；稳健策略默认推荐每周模板，不默认开启每日模板，任何周期任务都需用户确认后启用。
- 新建任务时至少选择一个机构公开研究源；默认选择 Morgan Stanley、Bridgewater、Goldman Sachs 和 J.P. Morgan。
- 有 OpenAI API Key 时，Responses API 使用 Web Search 并将 `allowed_domains` 限定为所选机构官方域名。优先搜索最近 30 天的行业相关公开材料，无结果时最多扩大到 90 天并明确日期。
- 只保存实际被 Web Search 采用且通过域名白名单校验的原文链接。没有官方原文时必须写“未找到可验证的机构公开材料”，不得用二次转载补齐。
- 不绕过登录、订阅、付费墙或版权限制；不得声称已获得客户专属或付费券商研报。机构观点与事实、AI 推断分开呈现。
- 设置可记录月度 AI 预算提醒；实际用量限制仍需在 OpenAI 平台配置。
- 支持“立即运行”“暂停”“恢复”和“删除”；删除任务不删除历史研报。

**每次运行流程**：

```text
调度器到期
  → 读取本地持仓和上一期研报
  → 真实模式下按相关持仓搜索少量长桥新闻
  → 有 API Key 时调用 OpenAI Responses API；否则使用本地模拟
  → 严格 JSON Schema 解码并附加确定性来源列表
  → 保存运行记录和研报
  → 在“行业研报”中标记未读结果并推进下次时间
```

**定时行业研报结构**：

- 研究范围、统计窗口和生成时间。
- 一句话结论与本期重要变化；没有实质变化时明确写“未发现重大变化”。
- 本期可验证变化；没有外部证据时明确写“证据不足”。
- 与相关持仓有关的长桥新闻标题、摘要和链接。
- 对当前持仓、行业集中度和投资论点的影响。
- 支持证据、反面证据、未知信息和后续研究事项。
- 与上一期简报的差异。
- 数据来源、链接、数据截止时间和生成所用模型。
- 明确标注“GPT 生成的个人研究材料”，不与券商研报或机构观点混淆。

**运行与补跑规则**：

- 单个任务运行期间禁止并发执行；成功保存后立即推进下一次时间，避免到期检查重复运行。
- 仅在 AI Invest 运行时检查任务；Mac 关机、休眠、应用退出或无网络时不承诺准点完成。
- 错过运行时间后，在设备恢复可用时只补跑最近一期，不为每个错过周期批量补生成。
- 长桥新闻搜索失败时仍可基于本地快照生成，但必须标注“证据不足”；GPT 或结构化解码失败时任务记为“运行失败”。
- 失败后保留“运行失败”状态和错误提示，不自动连续重试；用户修复连接后可手动运行。
- 任务全程只读长桥数据，不调用任何交易、订单或账户写入能力。

**实现边界**：

- AI Invest 使用产品自有的本地调度器、运行记录和 GPT API 调用链；GPT 负责研究推理，不负责保证定时触发。
- [OpenAI Scheduled tasks](https://learn.chatgpt.com/docs/automations) 可作为开发期间测试提示词和个人辅助工作流，但不作为 AI Invest 运行时依赖。官方说明本地项目任务需要电脑开机且桌面应用运行，因此产品必须自行处理后台运行、错过任务和恢复补跑。

#### 8.5.8 外部研报全文（P1）

- 支持用户手动导入 PDF、HTML、Markdown 或纯文本研报。
- 支持接入用户另行确认的长桥研报全文权限或其他合法数据源。
- 对全文进行分段、引用定位和结构化摘要。
- 选择最多三份材料比较共识、分歧、关键假设和风险。
- 严格遵守数据授权和本地缓存限制。

#### 8.5.9 验收标准

- 每个研究结论都能追溯到一个结构化字段、公告文件、新闻摘要或用户导入文档。
- 点击证据可以查看原始值、时间与来源链接。
- 只有标题或 URL 而没有内容时，系统显示“内容不足”，不生成全文摘要。
- 同一公告、新闻或数据期间不会因多次同步产生重复记录。
- 行业名称或层级无法映射时标记为未分类，允许用户手动修正。
- 删除研究缓存不会删除用户保存的论点和决策，但会提示某些来源可能无法离线查看。
- 用户可以创建、编辑、暂停、恢复、立即运行和删除定时行业研报任务。
- 每次运行可查看状态、开始和结束时间、研究窗口、数据新鲜度、GPT 成本、错误原因和生成结果。
- Mac 错过计划时间后只补跑最近一期，重复唤醒不会生成相同窗口的重复研报。

### 8.6 建议

“建议”是第三个一级 Tab，默认打开“待处理”，并提供“全部建议”“决策日志”和“周复盘”二级页面。

#### 8.6.1 建议生成机制（P0）

建议采用两阶段机制：

1. **确定性触发**：组合计算、风险规则、策略规则、数据质量和新研究事件先生成候选事件。
2. **AI 综合解释**：结合持仓、策略、基本面、评级、公告、新闻证据和历史决策，生成面向用户的建议卡。

用户也可在建议页明确确认一次 Codex CLI 生成。该请求实时检索最近 90 天公开信息，并结合价值投资、基本面分析、分散化、行为金融与仓位管理理论；新的待处理 Codex 建议替换旧的待处理 Codex 建议，本地确定性规则和已处理历史不受影响。

若没有确定性触发或可靠研究证据，AI 不主动创建买卖建议。MVP 对未持有标的只允许创建“加入观察列表”或“进一步研究”，不直接建议买入。

#### 8.6.2 建议类型（P0）

- 风险提醒：集中度、行业暴露、现金不足、异常波动。
- 策略偏离：仓位或行为不符合保存的策略规则。
- 论点复核：新事实、评级或预期变化、公告/新闻冲突或重大价格变化需要重新检查投资逻辑。
- 研究任务：信息不足，需要补充阅读或验证关键指标。
- 组合审视：提示评估再平衡，但不自动给出订单。
- 数据质量：行情、成本、行业或账户数据存在异常。

#### 8.6.3 建议卡结构（P0）

每条建议必须包含：

- 标题。
- 类型和优先级。
- 涉及持仓、行业或组合。
- 触发原因。
- 关联策略规则。
- 支持证据与反面证据。
- 可能影响。
- 可选行动，而非唯一指令。
- 主要风险与未知信息。
- 置信度：高、中、低，并说明原因。
- 数据和证据截止时间。
- 有效期或下次复核时间。
- 建议生成时间与模型版本。

#### 8.6.4 建议优先级（P0）

- **高**：数据异常可能导致判断失真；超过硬性风险阈值；关键论点疑似失效。
- **中**：接近阈值；新研究证据与当前论点冲突；需要本周处理。
- **低**：信息补全、一般观察或长期研究任务。

每日首页最多展示五条未处理建议；相同标的、相同规则、相同数据区间只保留一条活跃建议。

#### 8.6.5 建议状态（P0）

```text
待处理 → 已接受 → 已完成
   ├──→ 稍后提醒
   └──→ 已忽略
```

- 接受建议不代表执行交易，只表示进入用户行动清单。
- 忽略时可选填原因。
- 建议过期后进入历史，不自动删除。
- 所有状态变化写入决策日志。

#### 8.6.6 验收标准

- 不存在无触发原因、无来源且无“不确定”标记的建议。
- 建议中所有数值与程序计算结果一致。
- AI 无法读取必要数据时返回“证据不足”，而不是补全猜测。
- 建议不包含可直接执行的下单按钮。
- 用户可以查看某条建议使用了哪些数据、规则和研究来源。
- Codex 建议必须逐条展示来源标识，并只关联本次结构化来源列表中真实返回的 HTTPS 链接；生成失败时不得覆盖已有建议。

### 8.7 决策日志与复盘

本模块位于“建议”Tab 内，不作为独立一级菜单。

#### 8.7.1 决策日志（P0）

用户可记录：

- 决策日期。
- 涉及持仓或组合。
- 决策类型：继续持有、观察、研究、计划增减仓、更新论点、忽略建议。
- 决策理由。
- 使用的证据。
- 当时的组合和策略快照。
- 预期验证时间。
- 后续结果与复盘。

系统不执行“计划增减仓”，仅做记录。

#### 8.7.2 每周复盘（P0）

每周生成可编辑草稿：

- 本周组合变化与主要贡献来源。
- 新出现和已解除的风险。
- 策略偏离及处理结果。
- 重要财务、评级、公告、新闻和观点变化。
- 本周定时行业研报的关键变化和待验证事项。
- 已接受、忽略和完成的建议。
- 尚未验证的关键假设。
- 下周优先事项，最多五项。

#### 8.7.3 验收标准

- 每条历史建议都可以查看最终状态。
- 复盘草稿中的数字可追溯到当周组合快照。
- 用户可以编辑 AI 草稿，编辑内容不被下一次生成覆盖。
- 删除 AI 对话不删除结构化决策日志。

### 8.8 通知（P1）

- 支持 macOS 本地通知。
- 默认只发送高优先级风险、数据连接失败和定时行业研报完成通知。
- 每个标的同类提醒 24 小时内最多一次，除非风险等级提高。
- 用户可设置免打扰时段和关闭全部通知。
- 通知不显示敏感账户金额，除非用户主动开启。

### 8.9 侧栏底部设置与诊断

#### 8.9.1 设置项（P0）

- 长桥账户连接与同步范围。
- AI 服务凭证、模型和预算上限。
- 基础币种与基准指数。
- 风险阈值与提醒频率。
- 定时行业研报任务、默认时区、后台运行权限和错过任务处理方式。
- 数据缓存周期。
- 本地数据导出、备份和删除。
- 是否允许发送公告、新闻摘要或用户导入文档片段到 AI 服务。

#### 8.9.2 诊断（P0）

- 最近同步时间和每类数据状态。
- API 错误、限流和待重试任务。
- 定时任务的下次运行、最近运行、补跑、暂停和连续失败状态。
- AI 请求失败状态，不记录完整密钥。
- 数据库版本与应用版本。
- 一键生成脱敏诊断信息。

### 8.10 投资技能学习

“学习”是第五个一级 Tab，目标是让投资初学者在 4 周内只学习最必要的知识，并形成一套能用于真实复盘的个人方法论，而不是完成百科式课程。

#### 8.10.1 课程结构（P0）

- 课程共 28 天，每天约 20 分钟。
- 第 1 周：资产配置，产出个人资产配置与再平衡规则。
- 第 2 周：基本面与选股，产出统一的选股评分卡。
- 第 3 周：行业研究，产出行业价值链、周期、竞争、指标与风险模板。
- 第 4 周：综合实践，完成行业快照、公司分析、组合审计、压力测试和《个人投资手册 v1.0》。
- 每天包含学习目标、核心解释、港股或基金案例、误区或反方观点、实践练习、测验、复习问题和推荐 Codex 提问。

#### 8.10.2 页面与交互（P0）

- **今日学习**：展示当前课程、总体进度、理解信心、快速测验、完成状态和 Codex 提问入口。
- **学习路径**：按周展示 28 节课程、来源和完成状态，可查看任意课程详情。
- **投资人方法**：比较巴菲特、芒格和段永平的公开思想，展示核心原则、可执行流程、适用方法论页面、不能照搬之处、一手材料和 Codex 提问入口。
- **复习**：测验低于 80 分或理解信心低于 3 的课程自动进入复习清单。
- **我的方法论**：持续编辑资产配置规则、选股评分卡、行业分析模板、风险纪律和投资决策清单。
- **学习笔记**：记录自由笔记，可选择关联某一节课程。

#### 8.10.3 Codex 上下文与定时任务（P0）

- 项目使用 `Learning/` 作为应用和 Codex 的共享学习工作区。
- `profile.md` 保存目标、基础、偏好与隐私边界；`curriculum.json` 保存 28 天课程；`progress.json` 保存完成、测验和理解信心。
- `curriculum.json` 将投资人方法映射到相关课程日，`investors/` 保存三份长期上下文；每节课最多使用一个方法镜头，不延长 28 天主线。
- Codex 每天 08:00 运行一次，共 28 次；每次只生成一个缺失课程，同时写入人类可读 Markdown 与应用可导入 JSON。
- 应用由用户主动连接 `Learning/` 文件夹，并通过 macOS security-scoped bookmark 保留读写权限。
- 用户发起提问时，应用写入 `questions/current-context.md`，并复制带课程 ID 的提问；不依赖未公开的 Codex 私有深链。
- 从“投资人方法”提问时，上下文同时写入方法原则、局限、原始来源和个人方法论草稿；回答必须区分原始观点与 AI 解释。
- 项目提供 `$investment-learning-coach` Skill，统一课程生成、复习、答疑、来源与安全要求。

#### 8.10.4 数据与隐私（P0）

- 学习课程、进度、测验、方法论、笔记、设置和同步历史保存在本机 SQLite v3。
- 默认不向 Codex 提供持仓信息。
- 用户主动开启后，仅共享持仓代码、名称、资产类型和行业；不共享数量、成本、总资产、盈亏或交易记录。
- 课程用于教育和能力训练，不生成个性化买卖、仓位、时点、目标价或收益保证。

#### 8.10.5 验收标准

- 首次启动可看到完整 28 天课程路径，且数据库课程数为 28。
- 完成状态、理解信心、测验结果、方法论与笔记在重启后保留。
- 测验低于 80 分的课程会进入复习页。
- Codex 生成的合法 JSON 可覆盖对应内置课程，并显示“Codex 每日生成”来源。
- 不合法文件不会破坏现有课程，应用会提示被忽略的文件数量。
- 用户可从任意课程生成可被当前 Codex 项目读取的提问上下文。
- 用户可从三位投资人的方法页生成 Codex 提问上下文，并能查看公开原始材料和不能照搬的边界。
- 28 天结束后，用户可以独立完成一份资产配置方案、公司分析和行业分析，并说明证伪与退出条件。

## 9. 核心用户流程

### 9.1 首次使用

```text
安装应用
  → 连接长桥
  → 连接 AI 服务
  → 选择主账户和基准
  → 确认稳健策略模板
  → 首次同步
  → 查看组合体检
  → 为主要持仓补充投资论点
```

### 9.2 每日查看

```text
打开“持仓”
  → 查看数据时间
  → 查看组合变化
  → 处理高优先级风险
  → 阅读相关新研究事件
  → 接受、延后或忽略建议
```

### 9.3 公司与行业研究

```text
从“持仓详情”打开公司研究，或进入“行业研报”搜索行业
  → 打开公司研究卡或研究事件
  → 查看带来源的 AI 解读
  → 检查反面证据
  → 保存关键内容到持仓论点
  → 创建研究任务或更新决策日志
```

### 9.4 定时行业研报

```text
创建定时行业研报任务
  → 选择持仓行业、研究重点和频率
  → 立即试运行并检查来源
  → 保存并启用任务
  → 到期自动同步数据和生成研报
  → 在“持仓”或“行业研报”中阅读结果
  → 保存证据、创建研究事项或调整任务
```

### 9.5 每周复盘

```text
生成复盘草稿
  → 核对组合和收益口径
  → 回顾建议处理情况
  → 检查策略偏离
  → 更新投资论点
  → 确定下周最多五项任务
```

### 9.6 每日学习与 Codex 提问

```text
每天 08:00 Codex 生成下一节课程
  → 用户在“学习”中同步并阅读约 20 分钟
  → 完成练习、测验和理解信心记录
  → 更新个人方法论或学习笔记
  → 遇到问题时生成 current-context.md
  → 在 Codex 中继续追问
  → 错题与低信心课程进入复习
```

## 10. AI 系统要求

### 10.1 AI 职责

- 解释组合数据和异常，但不自行生成关键数值。
- 提炼和比较结构化研究数据、公告、新闻及用户导入材料，并保留原始来源。
- 按已保存的定时任务模板生成行业研报，并与上一期结果比较变化。
- 把规则事件、研究证据和策略上下文整理成建议。
- 主动列出反面证据、未知信息和结论适用范围。
- 根据用户历史决策调整表达与优先级，但不能悄悄修改风险规则。
- 根据 4 周课程、测验和理解信心生成每日学习内容，并持续辅导个人方法论；不能自动把课程标记为完成。

### 10.2 程序职责

以下内容必须由确定性程序完成：

- 市值、成本、盈亏和收益贡献计算。
- 组合、行业和单股权重计算。
- 风险阈值判断。
- 时间、币种和交易日处理。
- 数据去重、同步状态和权限控制。
- 定时触发、时区换算、错过任务补跑、幂等控制、重试和预算检查。
- 建议状态机和审计记录。

### 10.3 AI 可调用的产品工具

产品内部至少提供以下只读或受控写入工具：

- `get_portfolio_snapshot`
- `get_position_detail`
- `get_risk_events`
- `get_strategy`
- `get_investment_thesis`
- `get_industry_snapshot`
- `get_previous_industry_brief`
- `search_research_events`
- `get_evidence_excerpt`
- `get_decision_history`
- `draft_industry_report`
- `draft_recommendation`
- `save_research_note`

最后三个工具只能写入本地简报、草稿或笔记，不能写入券商账户。

### 10.4 输出约束

- 使用结构化输出，关键字段缺失时不创建建议卡。
- 每个事实标记来源类型：账户数据、行情、基本面、评级/一致预期、公告、新闻、用户导入、用户输入或 AI 推断。
- 结论必须带数据截止时间。
- 对无法验证的内容使用“未知”或“证据不足”。
- 不使用“必涨”“稳赚”“确定买入”等确定性金融表达。
- 默认输出简体中文；股票名称、机构名和引用保留原文。

### 10.5 质量评测集

MVP 上线前建立至少 35 个固定测试场景：

- 10 个组合风险和策略偏离场景。
- 10 个研究解读、来源引用和观点冲突场景。
- 5 个数据缺失或时间不一致场景。
- 5 个诱导模型给出无证据买卖结论的安全场景。
- 5 个定时任务幂等、数据过期、部分失败、预算不足和错过运行场景。

最低要求：

- 关键数值一致率 100%。
- 引用可定位率不低于 95%。
- 缺少证据时正确拒绝或降级率不低于 95%。
- 不产生交易执行行为，成功率 100%。

### 11.1.1 已知限制与产品处理

- 长桥行情总览文档与当前行情端点页面对港股默认实时权限的描述不完全一致。应用必须在连接后实际探测权限，并以返回数据时间为准，不在产品中预设“实时”。
- 行情接口限制为每秒不超过 10 次调用、并发不超过 5；单账户只允许一个长连接，最多同时订阅 500 个标的。SDK 会对 `QuoteContext` 主动限速。
- 历史 K 线按账户等级限制每月查询的唯一标的数量，官方页面给出的范围为 100–3,000 个。MVP 只为持仓和少量观察标的拉取，避免全市场扫描。
- 长桥 SDK 未列出 Swift。个人自用 MVP 采用官方 `longbridge` 终端作为稳定的进程边界，通过 JSON 读取 `auth status`、`check`、`portfolio` 和 `news search`；Swift 业务层不接触令牌或 SDK 类型。若未来商店分发，再评估官方本地服务或 XCFramework。
- 长桥 MCP 提供 100+ 工具和 OAuth 2.1，但同时包含交易工具。若后续使用 MCP，只向 AI 暴露明确的只读工具白名单。
- 传统 Access Token 一旦泄露可能被用于交易。产品默认不接收传统凭证，不在日志或环境变量中保存账户令牌。

### 11.2 同步策略

- 应用启动后进行增量同步。
- 用户可手动刷新。
- 持仓、账户、现金和价格：启动或用户手动刷新时读取；真实频率服从官方终端与账户权限。
- 行业新闻：每次真实研报运行时，只为范围内市值最大的至多 3 只持仓搜索，每只最多采用 2 条并去重。
- 机构公开研究：每次真实 GPT 研报运行时，仅在任务所选官方域名内检索；最多 6 次 Web Search 工具调用，保存实际采用的公开原文链接。
- 财务、估值、评级、一致预期、公告与历史 K 线：当前实现不自动同步，进入下一证据层里程碑。
- 定时行业研报：应用启动和运行期间每 15 分钟检查到期任务；错过后补跑最近一期并更新下次运行时间。
- 策略、笔记和决策日志：本地实时保存。
- 时间统一存储为 UTC，界面按 Asia/Hong_Kong 展示。

### 11.3 数据新鲜度

每类数据独立展示：

- 最近成功同步时间。

行情或持仓过期时，依赖该数据的建议自动降级，不使用旧数据制造紧急结论。

## 12. macOS 产品要求

### 12.1 平台

- 首期只支持 macOS。
- UI、导航、窗口、表格、图表、设置和系统交互统一使用原生 SwiftUI，不使用 Tauri、React 或 WebView 作为应用界面。
- 五个一级菜单使用 `NavigationSplitView` 实现；持仓明细、研究证据和学习内容可使用多栏布局与右侧检查器。
- 图表优先使用 Swift Charts；表格优先使用 SwiftUI `Table`，并提供原生排序、筛选和键盘操作。
- OAuth 使用系统认证会话打开长桥授权页，不在应用内自行保存网页登录状态。
- 使用 Swift Concurrency 处理同步、GPT 调用和后台任务；耗时操作不得阻塞主线程。
- 支持浅色和深色模式。
- 支持键盘导航和常用快捷键。
- 窗口尺寸变化时保证持仓表与研究阅读可用。
- 个人构建为了启动本机长桥官方终端暂时关闭 App Sandbox，并保留 Hardened Runtime；Mac App Store 分发前必须替换进程集成并恢复沙盒。

### 12.2 原生应用分层

```text
SwiftUI Views
  → View Models / App State
  → Swift Domain Services
  → Portfolio / Strategy / Research / Recommendation Engines
  → LongbridgeCLIService / OpenAIResearchService / InvestmentDatabase
  → 官方 longbridge JSON CLI / OpenAI Responses API / SQLite
```

- SwiftUI 视图只读取展示状态并发送用户意图，不直接调用长桥或 GPT。
- 持仓、策略规则、建议状态机和调度器保留为可测试的 Swift 业务模块。
- `LongbridgeCLIService` 只暴露连接检测、OAuth 启动、组合快照和新闻证据读取；不定义订单、改单或撤单方法。
- `OpenAIResearchService` 以机构官方域名白名单配置 Web Search，解析 `web_search_call.action.sources`，再次校验主机名后才把来源写入研报。
- CLI JSON 进入 Swift 层后立即转换为应用自己的值类型，避免外部字段扩散到界面和业务逻辑。
- 进程调用和网络请求统一封装为 `async/await`，错误转换为用户可理解的连接或降级状态。
- UI 自动化测试使用本地夹具和模拟适配器，不依赖真实长桥账户或实时网络。

### 12.3 本地优先

- 现金、持仓快照、价格时间序列和本地交易账本保存在版本化 SQLite 数据库。
- 账户快照、策略、笔记、建议和日志默认保存在本地数据库。
- 离线时可以查看最近一次同步内容。
- 需要联网的功能显示明确状态，不阻塞本地阅读。
- 到期研究任务仅在应用运行期间调度；用户可在设置中关闭自动检查，错过的最近一期在下次启动时补跑。
- 用户可以导出结构化备份。

## 13. 非功能需求

### 13.1 性能

- 本地缓存可用时，冷启动到可交互不超过 3 秒。
- 持仓列表搜索和排序响应不超过 300 毫秒。
- 正常网络下，增量账户同步目标不超过 10 秒。
- 单次公司研究卡或导入文档 AI 解读目标不超过 30 秒；超时后允许后台继续并显示状态。
- 单个 GPT 定时行业研报目标在 3 分钟内完成；大范围任务拆分执行并持续显示进度。
- 持仓首页最多加载必要摘要，详细图表按需加载。

### 13.2 可靠性

- 同步任务可重试且幂等，不因重复请求产生重复持仓、公告、新闻或研究事件。
- 定时研究以任务和研究窗口幂等；设备唤醒、应用重启或重复回调不会生成重复研报。
- 单类数据同步失败不阻塞其他模块。
- 数据库升级前创建本地备份。
- 应用异常退出后不丢失已保存的策略和决策日志。

### 13.3 安全

- 长桥 OAuth 令牌由官方终端加密保存且不进入应用；AI API Key 存储于 macOS Keychain。
- 日志、导出和错误报告不得包含完整令牌或密钥。
- 长桥访问层只封装资产、持仓、组合、行情和研究读取接口，不向上层暴露 `submit_order`、`replace_order`、`cancel_order`、DCA 创建/修改等写接口。
- 若使用 Longbridge MCP，只注册只读工具白名单；交易与自动化工具即使出现在服务端工具目录中，也不传给模型。
- 后台研究任务与前台分析使用相同的只读工具、预算和数据最小化策略，不因无人值守而扩大权限。
- 网络请求使用 TLS。
- 本地敏感缓存启用系统文件保护；后续可增加数据库级加密。
- AI 工具采用最小权限，不能执行本地任意命令或访问无关文件。

### 13.4 隐私

- 默认只把完成任务所需的最少组合字段、结构化研究字段和必要文本片段发送给 AI 服务。
- 设置中明确说明哪些数据会离开本机。
- 用户可关闭公告、新闻摘要和导入文档内容发送，此时仅使用本地确定性分析。
- 用户可分别删除账户缓存、研究缓存、AI 记录和全部本地数据。

### 13.5 可访问性与可读性

- 图表同时提供数值或表格表达，不只依赖颜色。
- 盈亏颜色之外增加正负符号和文字。
- 支持系统字号和 VoiceOver 基础标签。
- 风险等级使用文字、图标和颜色三重表达。

## 14. 风险与合规边界

- 应用界面明确说明：输出用于个人研究和决策辅助，不保证收益。
- 每条建议展示来源、时间、假设和主要风险。
- 不把机构观点冒充为客观事实。
- 不自动执行交易，也不生成可直接发送到券商的订单。
- 不通过高频提醒诱导用户交易。
- 如未来对外提供个性化投资建议、收费服务或交易连接，应另行进行牌照、数据授权、隐私和地域合规评估；不属于本 MVP。

## 15. 指标与成功标准

### 15.1 北极星指标

**每周完成一次有证据、有决策记录的组合复盘。**

不以短期投资收益作为 MVP 产品质量指标，因为收益受市场环境影响，且会诱导系统追逐短期行为。

### 15.2 产品指标

- 首次连接和同步完成率。
- 每周复盘完成率。
- 持仓拥有投资论点的覆盖率。
- 建议被查看、接受、忽略和完成的比例。
- 研究解读后保存为证据或笔记的比例。
- 定时行业研报任务的成功运行率、研报阅读率和任务暂停率。
- 高优先级风险从创建到处理的时间。
- 用户主动修正错误数据或错误关联的次数。

### 15.3 质量指标

- 账户和持仓对账一致性。
- 数据同步成功率和延迟。
- 研究来源可定位率。
- 定时行业研报准时或恢复补跑成功率、重复生成率。
- AI 数值错误率。
- 重复建议率。
- 无证据结论率。
- 应用崩溃率和本地数据恢复成功率。

## 16. MVP 发布验收标准

满足以下全部条件才视为 MVP 完成：

1. 可在 macOS 14 Apple Silicon 环境直接运行模拟模式，并可选配置长桥官方终端和 OpenAI 服务。
2. 可通过夹具验证长桥组合、现金、价格、汇率和新闻 JSON 映射；真实账户数值由用户完成 OAuth 后对账。
3. 可显示组合总览、混合来源持仓列表、行业分布和风险事件；可手动录入、编辑、删除基金、加密货币等长桥外资产，且重启和长桥刷新后不丢失。
4. 可创建“稳健港股”策略并关联持仓和投资论点。
5. 可查看行业视图，并从真实研报打开长桥新闻来源；公司研究卡、完整公告与基本面进入 P1。
6. AI 研究解读包含可查看的原始字段或来源链接和数据时间。
7. 可按行业筛选和归档研报，并为持仓行业创建、试运行、启停和删除 GPT 定时研报任务，查看运行历史和失败原因。
8. 设备错过计划时间后可在下次启动补跑最近一期，并更新下一次运行时间。
9. 组合集中度、行业集中度和现金缓冲规则可生成结构完整的确定性建议卡。
10. 建议可接受、忽略、延后、完成，并进入决策日志。
11. 可生成一份可编辑的每周复盘草稿。
12. 断网时可查看最近一次缓存数据，且不会把旧数据标成实时。
13. OpenAI API Key 使用 Keychain 保存；长桥令牌只存在官方加密缓存；日志无完整密钥。
14. 代码和界面均不存在下单、自动交易或券商写入路径。
15. Debug 与 Release 均可无代码签名构建，SQLite 完整性、持久化和服务映射检查通过。
16. 用户可导出周复盘 Markdown；完整数据库备份与一键清除进入 P1。
17. 五个一级 Tab 及核心页面均由原生 SwiftUI 实现；除系统 OAuth 授权和打开外部来源链接外，不使用嵌入式 Web 界面承载产品功能。
18. 学习模块包含完整 28 天课程、巴菲特/芒格/段永平方法库、SQLite 进度、复习、方法论、笔记和 Codex 上下文连接；每日 08:00 的 28 次课程生成任务处于启用状态。
19. 行业研报任务可选择四个机构官方公开研究源；真实 GPT 运行时域名白名单生效，实际采用的官方原文链接会保存，未找到时明确提示证据不足。

## 18. 主要风险与应对

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 长桥数据权限或字段不足 | 无法准确计算收益和风险 | 开发前做能力矩阵；按缺失项降级并明确口径 |
| 公司行动或资金流水不完整 | 成本和收益失真 | 对账状态、人工核对入口、避免伪精确收益率 |
| 长桥无公开券商研报全文端点 | 无法按原设想建立全文研报库 | P0 改为结构化行业研报中心；P1 支持合法文档导入或另行授权接口 |
| 港股行情权限文档描述不一致 | 可能只有延迟行情或无推送 | 启动时探测权限和数据时间，功能按实际等级降级 |
| 历史 K 线唯一标的月度配额 | 全市场研究会快速耗尽配额 | MVP 只同步持仓和少量观察标的，缓存并增量更新 |
| 长桥没有官方 Swift SDK | 原生应用需要稳定的进程边界，商店沙盒下无法任意启动外部 CLI | 个人版使用官方 JSON CLI；分发版再评估官方本地服务或 XCFramework，并恢复 App Sandbox |
| AI 幻觉或错误引用 | 误导投资判断 | 结构化输出、引用校验、证据不足时拒绝生成 |
| 建议过多导致焦虑或过度交易 | 偏离稳健定位 | 首页最多五条、去重、默认低频提醒 |
| 模型成本不可控 | 长期使用成本过高 | 缓存摘要、增量分析、预算上限、手动重算 |
| Mac 关机、休眠或后台权限关闭 | 定时行业研报无法准点生成 | 显示运行条件；恢复后只补跑最近一期；保留手动立即运行 |
| 定时任务重复触发或连续失败 | 重复成本或产生噪音简报 | 成功后立即推进下次时间；失败不自动连环重试，保留手动重跑 |
| 本地数据损坏或丢失 | 策略和日志无法恢复 | 自动备份、数据库迁移保护、可导出文件 |
| API 限流或网络不稳定 | 数据不及时 | 增量同步、退避重试、缓存和数据新鲜度提示 |

## 19. 真实账号与 P1 确认清单

- 确认是否另有未公开的长桥券商研报全文权限；若没有，按 P1 文档导入方案执行。
- 确认 P1 研究层继续扩展官方 CLI，还是接入只读 Longbridge MCP；持仓和关键数值仍使用确定性数据层。
- 默认主基准采用恒生指数、恒生国企指数还是恒生科技指数。
- AI 服务使用的模型、API Key 方式和每月预算上限。
- 定时行业研报默认频率、允许后台运行的系统权限，以及单次和月度 GPT 预算。
- 本机最低 macOS 版本，以及 MVP 是否只支持 Apple Silicon 或需要 Universal Binary。
- 若准备分发应用，决定官方本地服务、C/C++ 或 Rust XCFramework 方案，并在恢复 App Sandbox 后完成打包验证。
- 是否需要在首个版本支持第二个长桥账户。
- 初始化风险阈值是否采用本文默认值。
