## 本轮修复

- 现金类持仓不再产生虚假投资盈亏，也不再进入最大证券持仓和行业集中度。
- 行业观察改为按实际持仓动态计算，移除写死的行业结论。
- 研报异步完成后按任务 ID 更新，避免删除或排序变化导致越界和错写。
- 到期任务失败后退避一小时，避免每 15 分钟重复消耗 API。
- 长桥子进程增加 45 秒超时、取消处理和可理解的错误提示。
- 内置课程会在升级后刷新，同时保留学习进度和 Codex 自定义课程。
- 模拟研报不再声称取得实时指数或机构观点。
- 持仓与交易数值增加有限值校验，拒绝无穷大和非数字输入。
- 未连接 Learning 文件夹时，Codex 提问弹窗提前提示并禁用提交。
- 设置窗口改为分组布局，数据库失败时展示具体错误；未实现的基准超额收益明确标注为 MVP 限制。
- 新增可重复执行的核心回归脚本，并纳入统一验证入口。
- 新增 Codex CLI 动态策略与建议：实时 Web Search、只读临时会话、金融理论约束、可点击来源和失败不覆盖。

## 尚未闭环的外部验收

以下项目依赖本机账号或分发环境，本轮没有伪装成已验证：

- 本机没有安装或登录长桥官方组件，因此尚未验证真实 OAuth、组合返回结构和新闻搜索结果。安装后应在“设置 → 账户”完成一次连接、同步和断网恢复测试。
- 本机未配置 OpenAI API Key，因此没有产生真实 API 调用或费用。网络请求结构、输出解析和域名边界已用完全本地的 URL 桩验证；配置 Key 后仍应手动生成一份研报并核对实际来源链接。
- 本机 Codex CLI 已登录，并以只读临时会话完成一次真实 Web Search 与严格 JSON Schema 冒烟；正式组合的策略/建议生成仍留给用户在界面确认后执行，验收过程没有发送正式持仓。
- 定时任务只在 Mac 开机且应用运行时触发，不是系统级常驻任务；月度预算只做记录，不会替代 OpenAI 平台用量限制。
- 当前验证构建关闭代码签名。个人在 Xcode 中运行没有问题；若对外分发，还需要 Developer ID 签名、公证和安装包验收。

## 建议的首次真实数据验收

1. 先备份 `~/Library/Application Support/AIInvest/AIInvest.sqlite`。
2. 连接长桥并同步，核对总现金、三只最大持仓、币种和汇率折算。
3. 录入一项小额基金或加密资产，重启应用确认仍存在。
4. 记录一笔不更新现金的历史交易，确认只进入本地账本。
5. 配置 OpenAI Key，手动运行一个单行业任务，逐条打开来源并核对机构、标题和发布日期。
6. 连接项目 `Learning` 文件夹，生成一次 Codex 提问上下文，确认未授权时不包含持仓信息。
7. 分别手动生成一次 Codex 策略和建议，核对来源、理论依据、持仓匹配和生成前后的本地规则/历史保留情况。
